# Canon i9950 Printer Overview

## Product Summary

The Canon Bubble Jet **i9950** is a wide-format photo inkjet printer released circa 2004, aimed at professional and enthusiast photographers. It supports A3+ (13×19 inch) borderless printing with an 8-ink ChromaPLUS system.

**Internal model designation:** K10238 (shared with i9900 and PIXUS 9900i)

## Regional Variants

| Model | Region | Distinguishing Features |
|-------|--------|----------------------|
| **i9950** | Europe, UK, AU, HK, CN, TW, etc. | CD/DVD printing tray; fixed print head (EU variant lore) |
| **i9900** | USA, Canada, Korea | User-replaceable print head (QY6-0055-000); no CD tray |
| **PIXUS 9900i** | Japan | Same platform as i9950 |

Canon documentation states: *"The operations are exactly the same with the i9900"* (Quick Start Guide). Hardware is substantially identical; regional SKUs differ mainly in power supply, accessory cover (CD tray), and marketing name.

## Ink System (8-Color ChromaPLUS)

Individual ink tanks (Single Ink technology):

| Tank | BCI code | Role |
|------|----------|------|
| Black | BCI-6Bk (4705A003) | Text, dark tones |
| Cyan | BCI-6C (4706A003) | Process color |
| Magenta | BCI-6M (4707A003) | Process color |
| Yellow | BCI-6Y (4708A003) | Process color |
| Photo Cyan | BCI-6PC (4709A003) | Photo detail |
| Photo Magenta | BCI-6PM (4710A003) | Photo detail |
| Red | BCI-6R (8891A003) | Extended gamut |
| Green | BCI-6G (9473A003) | Extended gamut |

Red and green inks expand saturation in orange and green hues beyond typical 6-color systems.

**Print head (i9900, user-replaceable):** QY6-0055-000

## Interfaces

| Interface | Specification | Notes |
|-----------|---------------|-------|
| USB 2.0 Hi-Speed | Up to 480 Mbps | Primary PC connection; certified cable ≤3 m |
| USB 2.0 Full Speed | Up to 12 Mbps | Secondary USB port on printer |
| IEEE 1394 (FireWire 400) | — | Mac OS 9 / OS X option |
| Direct Print Port | PictBridge / Bubble Jet Direct | Front panel camera connection |

This driver project targets **USB 2.0 Hi-Speed** only. FireWire and PictBridge are out of scope.

## Supported Paper Sizes

Letter, Legal, 4×6, 5×7, 8×10, 11×17, 13×19 (A3+), US #10 envelopes, and various Canon media types (Photo Paper Pro, Plus Glossy, Matte, HR paper, transparencies).

Gutenprint defines max printable width as **933 points (~329 mm)** and height **23 inches** for the i9900/i9950 family.

## Software Bundled (Original)

Windows/Mac CD included: printer driver, Easy-PhotoPrint, PhotoRecord, ZoomBrowser EX / ImageBrowser, PhotoStitch, electronic user guide.

## Exif Print

Supports Exif Print standard for optimized output when connected to compatible digital cameras.

## Energy

ENERGY STAR qualified.
